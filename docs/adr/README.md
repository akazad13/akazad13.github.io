## ADR Lifecycle

```
PROPOSED ──> ACCEPTED ──> SUPERSEDED / DEPRECATED
```

- **Proposed**: Under review or draft status.
- **Accepted**: Ratified and actively governing the repository.
- **Superseded**: Replaced by a newer ADR (explicitly referenced).
- **Deprecated**: No longer applicable.
